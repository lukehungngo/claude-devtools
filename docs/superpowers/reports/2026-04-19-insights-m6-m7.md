## Deviations from Plan

1. **Route path fix (unplanned):** Existing `/api/insights/aggregate` and `/api/insights/activity` routes had a double `/api/` prefix (server mounts at `/api`, routes had `/api/` baked in). Fixed in commit `2f0ad1c` to match correct pattern established by M6/M7 routes.

2. **Verdict metric correction:** The trends-aggregator initially used `weeklyCalls` (call frequency) for the linear regression verdict. Reflect agent identified this as a spec mismatch — spec requires token volume (`weeklyIn[i] + weeklyOut[i]`). Fixed in commit `4d3562d`.

3. **PlaceholderCard removal:** The `PlaceholderCard` component and `PlaceholderCardProps` interface were left unused after M6/M7 wiring. Removed in a bug-fix commit to clear ESLint warning.

4. **Commands always "stable":** Commands are detected from user text events which carry no token counts (`tokensIn: 0`, `tokensOut: 0`). With token-volume verdict, all command weekly buckets sum to 0, so `computeVerdict` returns "stable" for all commands. This is an intentional limitation documented in `trends-aggregator.test.ts` — call frequency would be more meaningful for commands, but the architecture maps token attribution only to assistant events.
